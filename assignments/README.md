# 作业安排

课程包含八次作业。前两次使用本地模型，分别学习输出评估和工具执行；后六次在同一个个人产品 fork 中持续开发。每次作业的实现要求、验证方法和提交材料见对应正文。

| 周次 | 作业 | 与前后作业的关系 |
|---|---|---|
| W1 | [HW1 图表规格与评估](HW1.md) | 从流程描述生成规格，建立比较和评估方法，为下一周导出一份图表 |
| W2 | [HW2 文件修改 Agent](HW2.md) | 实现读取、修改、复查工具与控制循环，再通过 MCP 调用工具 |
| W3 | [HW3 在项目中实现名称检查](HW3.md) | 从固定教学提交开始开发，将前两周的需求分析和验证方法用于真实应用 |
| W4 | [HW4 检查系统与任务交接](HW4.md) | 扩展名称检查，实现多页规则、配置和统一报告 |
| W5 | [HW5 CLI 与 CI](HW5.md) | 复用检查核心，实现批处理、报告比较和 PR 自动检查 |
| W6 | [HW6 系统测试与安全验证](HW6.md) | 对已有功能进行分层测试，验证输入限制，并复现和修复缺陷 |
| W7 | [HW7 代码审查与交付判断](HW7.md) | 审查此前的跨模块修改，核实意见，确定下一周使用的候选版本 |
| W8 | [HW8 完成产品工作流](HW8.md) | 集成检查面板、问题定位、异步状态和报告导出 |

W9 按[运行实践](../weeks/week09.md)完成运行信息记录、故障恢复和性能分析。W10 按[交付实践](../weeks/week10.md)开展交叉试用，根据反馈修改产品并演示。两周继续使用 HW8 的代码，各提交一次 PR。

数据格式与跨作业行为见[共同约定](../docs/contracts.md)，分支和报告的提交方法见[开发与提交](../docs/collaboration.md)。HW3–HW8 按功能与用户需求（35%）、设计与接口（20%）、验证与问题处理（25%）、Agent 使用及人工决策（20%）评分。
