# 独立短变更审查练习

[review-candidate.mjs](review-candidate.mjs) 是一项虚构 PR 修改后的代码。请依据以下产品约定审查：

- 使用 `pageId`、`cellId` 和 `ruleId` 共同识别问题。
- 空白名称应当被识别为缺少名称。
- 执行失败时，问题计数为未知。
- 改变问题数组的排列顺序，不应影响报告比较结果。

先在课程仓库中阅读候选代码，再将它复制到产品仓库的 `course-labs/review`，保留为练习中的修复前版本。这里的文件是虚构 PR 的修改后代码，也是你随后修复练习的起点。

用 `node:test` 或 Vitest 编写最小输入，验证审查判断并记录失败。然后另存修复版本，重新运行相同测试，说明每项修改对应哪条约定，最后与教师讨论核验结果。

练习文件及测试保存在 `course-labs/review`，随本周 PR 提交。报告中将本练习与实际产品的审查分别记录。
