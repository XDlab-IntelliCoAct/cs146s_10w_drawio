# Agent 任务说明模板

将下列栏目补充为本次任务的具体内容，再提供给 Agent。文件、符号和命令应使用当前仓库中的实际名称；相关接口较长时，可以链接到文档对应章节。

## 用户需求与完成条件

说明用户遇到了什么问题，本次希望增加或改变什么行为。列出典型操作和预期结果，使 Agent 知道怎样判断任务完成。

## 当前代码与前置工作

填写当前分支、前次 PR 和相关模块，说明哪些功能已经实现。列出本次修改范围，以及需要保持的已有行为。

## 输入、输出与接口

提供输入输出样例，引用本次适用的共同约定。说明空输入、错误输入和执行失败时应怎样处理。

## 需要阅读的代码

填写文件、函数或状态名称，并给出具体阅读问题，例如“图表编辑后哪个状态保存最新 XML”。

## 运行与验证

填写命令的执行目录，以及安装、启动、测试和构建命令。指出哪些案例用于检查本次行为。

## 换会话继续时补充

说明已完成内容、当前失败、复现步骤和待处理事项，提供相关提交或 diff。请新会话先复述对目标及接口的理解，再继续实现。
