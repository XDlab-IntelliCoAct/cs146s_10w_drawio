# CS146S：使用 Agent 开发真实软件

本课程以 AI 画图产品为开发对象，带你完成一项图表交付前的检查功能。用户可以发现图中的问题，定位相关图元，修改后重新检查，最后导出报告。

课程共十周。前两周使用本地 Ollama 模型，学习输出评估、工具调用和 Agent 执行控制。从第三周开始，你将使用自己的 Coding Agent，在 [Next AI Draw.io 教学项目](https://github.com/NewPhrexian/next-ai-draw-io_cs146s) 中持续开发。前八周各完成一次作业，最后两周运行完整产品，根据用户反馈改进功能并完成交付。

## 开始学习

首次学习请先读[课程学习路线](docs/learning-route.md)，了解两个个人仓库的用途，以及各周内容之间的关系。然后打开[十周安排](syllabus.md)，进入当前周的学习页，完成所需的环境准备和引导示例，再阅读本周作业。

每周学习页解释本周要解决的问题和需要了解的知识；作业页说明具体实现要求、验证方法和提交内容。遇到接口或源码问题时，再查阅下方的参考文档。

## 课程各阶段的开发内容

| 阶段 | 主要内容 |
|---|---|
| W1–W2 | 比较图表规格的生成方法，编写能够修改并复查图表的本地 Agent |
| W3–W4 | 在应用中实现名称检查，扩展多页规则、配置与统一报告 |
| W5–W7 | 实现批量 CLI 和 CI，完成系统测试、安全验证与代码审查 |
| W8 | 完成检查面板，支持问题定位、结果更新和报告导出 |
| W9–W10 | 诊断和恢复运行故障，分析性能，根据试用反馈迭代并交付产品 |

前两周在个人课程 fork 中修改 Python 程序并提交作业；W3 起在个人产品 fork 中开发 TypeScript 功能。每周的代码、测试和报告通过独立 PR 提交，具体操作见[开发与提交](docs/collaboration.md)。
