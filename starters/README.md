# 实验起始代码

前两周使用本目录中的 Python 代码。HW1 在 `hw01` 中实现模型调用、输出检查和批量实验；HW2 在 `hw02` 中实现工具、Agent 控制循环及相关测试。代码中的 TODO 对应作业要求，完成相应函数后，再运行作业中的整组实验命令。

课程已提供 `shared/diagram_io.py`，用于解析和修改前两周的小型图表文件；`hw01/preview.py` 用于将图表规格转换成预览文件。这些辅助代码可以直接使用，测试位于课程的 `tests` 目录。HW3 起，在个人产品 fork 中阅读并使用真实项目的多页和压缩页面处理方法。

环境准备命令在课程仓库根目录执行，步骤见[环境准备](../docs/setup.md)。模型原始输出与练习文件保存在本地 `.runtime/` 中，每次运行使用独立目录或文件名，以便回查。
