# 共同检查场景

各周的完成标准见作业正文。本页汇总需要在检查核心、CLI 和界面之间保持一致的行为，可用于设计测试、检查 PR 和验证最终交付。具体字段及结果定义见[共同约定](contracts.md)。

## 模型与 Agent

| 阶段 | 输入/操作 | 检查 |
|---|---|---|
| HW1 | 三方式、dev/eval、两次重复 | 配置和提示版本清楚，结构/关系/含义分别判断 |
| HW1 | 缺失与冲突 | 已知信息保留，未确定部分可识别 |
| HW2 | 同轮两个工具 | 各调用有实际结果并回传 |
| HW2 | 错误参数/未知工具 | 拒绝执行，有原因 |
| HW2 | 旧版本修改/重复连接 | 文件保留，冲突可识别 |
| HW2 | 模型失败/上限 | 结束原因、调用次数和文件状态可核对 |
| HW2 | MCP | 初始化、发现和同一工具的实际调用；isError=false 且工具结果 ok=true |

## 规则、配置与报告

| 输入/操作 | 预期 |
|---|---|
| normal / compressed | 语义结果一致，没有四项规则问题 |
| labels / html-label | n2 缺名，其他步骤不误报 |
| multi-page | page-b/n2 缺名，page-a/n2 不受影响 |
| grouped | 分组、空注释、装饰、包装注释不误报为步骤 |
| free-endpoint + flowchart/sketch | 缺端点规则启用/关闭；孤立步骤独立判断 |
| dangling | 非空端点不存在为 error |
| empty | 有效空页完成，步骤 0，结构根计入 cells |
| invalid / DTD / 超限 / 无效配置 | invalid、原因明确、未知统计为 null |
| 同页重复 ID | invalid；不把图元合并 |
| 同输入重复检查 | 除生成时间等元数据外稳定，输入不变 |
| 排列变化/坐标平移 | 问题集合不变 |
| 只改某页/补名 | 只改变相关问题 |
| 报告比较 | 新增/解决/持续；时间不产生问题差异；未完成检查的报告不可比较 |
| 配置不同/范围不同 | 配置变化提示；范围不同拒绝比较 |

## CLI 与 CI

单文件检查正常完成且未达到阈值时，退出码为 `0`；达到阈值时为 `1`；执行或参数错误时为 `2`。`batch` 目录的四个文件中有一个无效，检查其他文件的结果仍需保留，最终返回 `2`。

逐项验证目录文件的处理顺序、默认不递归、不跟随链接、输出覆盖保护和输入只读。显式指定产品目录外的输出时，核对实际路径；写入失败时，确认旧报告仍然存在。`dry-run` 不写文件，也不创建目录。比较命令收到不兼容报告时返回 `2`。

在个人 fork 的 PR 中实际运行正常案例，确认 JSON 报告可以下载。另建演示 PR，验证工作流确实因预期原因失败。

## 界面与运行

- 当前页/全部页与 CLI 报告一致。
- 不同页面具有相同图元 ID 时，定位仍然正确；目标已删除时，界面提示重新检查。
- 空图、检查中、成功、失败和结果过期时，界面分别提供可理解的反馈。
- 任务 A 晚于新任务 B 返回时，不覆盖 B 的结果；离开会话后，原任务不更新旧界面。
- 图表编辑、AI 修改和版本恢复正确更新有效性。
- 筛选不改变完整导出；报告对应当时快照。
- AI 操作先填入，再由用户确认发送。
- 标签按安全文本显示；键盘操作和焦点移动正常，窄窗口和长标签不会妨碍使用。
- 三类故障均有复现与恢复记录，A、B 任务顺序测试注明所用执行器；生产构建能够完成实际用户流程，性能优化前后的检查结果一致。
- 干净目录可按文档复现，交叉试用反馈完成迭代。
