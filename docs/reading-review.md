## 中文表达与教学说明

学习路线按两个仓库、模型与 Agent 的用途、各阶段学习内容和命令运行顺序组织。每周学习页说明学习目的和阅读准备，作业页保留具体实现、验证与提交要求。

各篇正文逐段检查动作与对象、术语指代及前后关系。修改中补充了输入快照、结果过期、退出码、模块接口和测试层次的解释；后期作业继续保留批处理、系统测试、多轮审查、异步任务、故障恢复和跨模块迭代要求。脚本的教学注释和帮助文字与文档一同核对。

接口字段、规则 ID、退出码、输入限制、命令参数和固定教学提交继续按[共同约定](contracts.md)维护。15 份原始课件的内容与来源保留。课程检查脚本检查文档结构、链接及材料一致性，正文表达另行通读。
